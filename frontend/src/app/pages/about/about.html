PROJECT INFORMATION

About GDELT-Lab

An experimental research environment for investigating global news data and evaluating its potential for a news intelligence platform.

Project overview

GDELT-Lab is a research prototype exploring how publicly available GDELT datasets can be collected, stored, inspected and analysed. The work supports the investigation of a larger Global News and Public Affairs Intelligence Platform.

The prototype provides a local environment for examining structured event records, event mentions and Global Knowledge Graph data without relying exclusively on live API requests.

Research objectives

01

Evaluate data sources

Investigate GDELT services and determine their suitability for the platform's research and analytical requirements.

02

Build a data ingestion workflow

Collect source files, extract their contents and import records into a local database for repeatable inspection.

03

Understand the underlying records

Explore the structure of Events, Mentions and GKG datasets, including their fields, themes and geographic information.

04

Inform the wider platform design

Use the research findings to guide future decisions about ingestion, storage, searching and analysis.

Technology stack

The prototype combines a web frontend, a backend API and a local data store.

FRONTEND

Angular

TypeScript-based interface for browsing datasets and research findings.

BACKEND

ASP.NET Core

API endpoints for local dataset access and ingestion statistics.

DATA

SQLite

Local database used to store the imported research records.

SOURCE

GDELT

Global event, event-mention and knowledge-graph datasets under investigation.

Current scope and limitations

  • The current dataset represents the files collected for this research, not the entirety of GDELT.
  • External API availability and rate limits can affect exploratory testing.
  • Readable theme labels may be generated from theme codes and should not automatically be treated as officially verified definitions.
  • Advanced cross-source analysis and intelligence features remain future development goals unless demonstrated elsewhere in the prototype.
